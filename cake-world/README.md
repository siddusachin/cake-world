# Cake World

Responsive cake catalogue with WhatsApp enquiries. React + TypeScript + Tailwind CSS + React Router.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # outputs dist/

- WhatsApp number and contact details: `src/config/siteConfig.ts`
- Products, categories, combos, slides, testimonials: `src/data/`
- Images: put files in `public/images/...` and set `imagePath` (e.g. "/images/products/red-velvet.webp"). An empty or broken path shows the placeholder.
- All prices, offers and testimonials are SAMPLE content. Replace before launch.
